# Mobile Product Roadmap

This roadmap is ordered for a mobile-first cricket game. The goal is to ship a version that feels complete and fast on a phone before expanding into broader long-term content.

## Must-Have

These are required for the game to make sense as a mobile product.

### Control and Onboarding

- Touch-first batting, bowling, and fielding controls.
- First-run tutorial that teaches each core control in under a minute.
- Practice drills for batting timing, bowling release, and fielding response.
- Configurable camera, control sensitivity, and input assists.

### Session and Access

- Quick Match and Nets mode for short sessions.
- Offline play for training, quick matches, and basic progression.
- Save/resume for interrupted mobile sessions.
- Session lengths that work in 2-5 minute windows.
- Reliable fallback logic for partial lobbies or no-lobby play.

### UI and Performance

- Lightweight UI that stays readable on a phone screen.
- Device/performance tiers so low-end phones can run the game.
- Clear timing, line, and length feedback.
- Mobile-safe battery and loading behavior.

### Progression

- Basic progression that works even when the player only has a few minutes.

## Should-Have

These features make the game competitive with the current mobile market.

### Retention and Depth

- Daily missions and reward loops.
- Short tournament ladders or seasonal events.
- Burst-friendly career progression.
- Mobile-friendly replay or highlight support.
- Stronger commentary and match feedback.
- Better onboarding for returning players after a long break.
- Basic customization for squads, kits, and player identity.
- Stronger fielding assist options for touch play.
- A more explicit retention loop that gives the player reasons to return daily.

## Later

These are valuable, but they should not block the first good mobile release.

- Deeper live-ops events.
- Advanced cosmetic systems.
- Social sharing and community content exchange.
- Expanded career narrative layers.
- More complex online competitive ladders.
- Spectator/replay tools beyond simple highlights.
- Extra mode variants once the touch core is stable.

## Delivery Order

1. Make the touch controls feel good in Nets.
2. Make quick matches work offline.
3. Add save/resume and mobile UI polish.
4. Add the short-session retention loop.
5. Expand into career, events, and richer social play.

## Release Gate

The mobile version should not ship until these are true:

- New players can learn batting, bowling, and fielding quickly.
- A full short match can be completed on a phone without friction.
- The UI remains readable on small screens.
- Performance is stable on the lowest supported device tier.
- The game still feels worthwhile when played offline.
